# @nejcm/dev-toolbar

Extensible, low-overhead in-app developer toolbar for React applications.

It is meant to be an internal developer platform rather than a row of counters:
runtime-health signals, feature-flag toggles, environment and actor inspection,
visual debugging overlays, project-specific tools, and diagnostic snapshots —
all without leaving the current screen.

The full design document lives in [dev-bar.md](./plans/dev-bar.md).

## Status

Early scaffolding. The public API is not stable yet.

## Install

```bash
npm install @nejcm/dev-toolbar
```

## Development

```bash
npm install
npm run typecheck
npm run build
```
